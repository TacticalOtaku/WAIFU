# WAIFU: World Audit & Integrity

Панель диагностики мира и безопасного автоисправления для Foundry VTT v14+.

Находит тяжёлые многоуровневые сцены, битые ссылки `@UUID`, раздутые настройки мира и забытые флаги удалённых модулей, а также проверяет отдельных актёров и предметы.

## Установка

В окне модулей Foundry VTT (**Дополнительные модули → Установить модуль → Manifest URL**) вставьте ссылку:

```text
https://github.com/TacticalOtaku/WAIFU/releases/latest/download/module.json
```

**Требования:** Foundry VTT 14, любая игровая система, без сторонних зависимостей.  
**Ручная установка:** скачайте `waifu-v<версия>.zip` со страницы [GitHub Releases](https://github.com/TacticalOtaku/WAIFU/releases/latest), распакуйте в `Data/modules/waifu` (чтобы `module.json` лежал в корне папки) и включите **WAIFU: World Audit & Integrity** в управлении модулями.

## Обзор

WAIFU проверяет мир Foundry VTT целиком и рассчитывает индекс целостности (`0-100%`). В отчёте собраны проблемные сцены, битые ссылки `@UUID`, раздутые настройки мира и остаточные флаги модулей, а графики SVG и метрики показывают распределение нагрузки.

При первом открытии, пока сохранённого отчёта нет, WAIFU сам сканирует мир и записывает результат. При следующих входах сразу открывается этот снимок. После очистки настроек, флагов или ссылок отчёт обновляется локально на месте без повторного сканирования мира; свежую проверку всегда можно запустить вручную кнопкой в шапке.

> [!NOTE]
> Модуль рассчитан на Foundry VTT v14 (включая многоуровневые `Scene.levels`, `ApplicationV2` и блоки Loreframe в журналах) и полностью переведён на русский и английский. Внешний вид повторяет AIM: Actor Window: темы Ночь и Пергамент, шесть цветовых акцентов и встроенный шрифт Onest Variable.

## Как открыть WAIFU

Любой **GM** может открыть модуль четырьмя способами:

| Точка входа | Где найти |
| --- | --- |
| **Элементы управления сценой** | Слой `Tokens` → иконка стетоскопа (**WAIFU: Аудит и целостность мира**) или коробок (**WAIFU: Аудит актёров и предметов**) |
| **Боковая панель настроек** | Вкладка «Настройки игры» → кнопка **Открыть аудит мира (WAIFU)** |
| **Настройки модулей** | Настройка параметров → WAIFU → **Открыть аудит WAIFU** или **Открыть аудит актёров и предметов** |
| **Макрос / Консоль** | `game.modules.get("waifu").api.open()`, `WAIFU.open()` или `WAIFU.openEntityAudit()` |

## Рабочая область

Внутри окна три уровня: компактная шапка, общий хаб с карточками и подробные разделы с выдвижными инспекторами сцен. В окнах шириной меньше `860 px` сетка автоматически складывается в вертикальный список.

| Раздел | Что показывает в хабе и внутри |
| --- | --- |
| **1 · Индекс целостности и тренд** | Шкала здоровья `270°`, полоса штрафов, мини-график и сравнение с JSON. Внутри открываются подробный тренд с дельтами, разбор штрафов, матрица проблем по разделам и распределения сцен (`Мин / Средн. / Медиана / P95 / Макс`). |
| **2 · Автофикс и обслуживание** | Три приоритетных исправления в один клик и системные предупреждения. Внутри: очередь Dry-Run с чекбоксами, опция JSON-бэкапа (включена по умолчанию), архивация чата, чистка пустых боёв, поиск битых медиафайлов 404, неиспользуемых файлов `waifu-optimized` и список исключений. |
| **3 · Сцены и медиафайлы** | Число здоровых и тяжёлых сцен, соотношение WebP и PNG и две самые тяжёлые сцены (клик открывает инспектор сцены). Внутри: график мегапикселей против лимита, фильтры, мультивыбор с `Shift+Click` для пакетных действий (WebP, стены, токены, свет, исключения), сортируемая таблица уровней `Scene.levels` и тайлов и переход к сцене на холсте. |
| **4 · Ссылки `@UUID` и якоря** | Доля целых ссылок и топ проблемных документов. Внутри: графики по типам (`JournalEntry`, блоки Loreframe, `Actor`, `Item`, `RollTable`, `Macro`, `Scene`), проверка `#якорей`, фильтры, подбор похожих замен, ручной выбор цели, синхронизация `{текста}`, замена, отвязка с сохранением текста и исключения (по одной ссылке и пачкой). |
| **5 · Хранилище БД и флаги** | Объём данных, которые можно безопасно убрать, и список модулей. Внутри: диаграмма размеров БД, сортируемые таблицы настроек мира и флагов документов с мультивыбором (`Shift+Click`) для массового удаления или скрытия без повторного сканирования мира, просмотр JSON, экспорт бэкапа и восстановление из JSON. |
| **6 · Студия отчёта и пороги** | Плитки текущих лимитов и кнопки выгрузки (`.html`, `.md`, `.json`, запись журнала). Внутри: отложенный предпросмотр отчёта (Визуальный, Markdown, Журнал) с кэшированием по ревизии и встроенным редактором всех 15 порогов аудита. |
| **7 · Аудит актёров и предметов (JSON)** | Встроенная вкладка и отдельное окно (`WAIFU.openEntityAudit()`), по умолчанию пустое. Принимает `Actor`, `Item`, `Folder` (включая вложенные подпапки) и компендиумы `Actor`/`Item`: ищет и удаляет забытые флаги, `prototypeToken.flags`, `ActiveEffect.changes`, ссылки `@UUID` и пути `modules/<id>/` от удалённых или отключённых модулей без полного аудита мира. |

### Сохранение отчёта и экран статуса

- **Автоаудит только при первом входе:** пока сохранённого отчёта нет, WAIFU сканирует мир при открытии. Потом открывается готовый снимок, а повторные аудиты запускаются вручную.
- **Локальное обновление:** чистка настроек, флагов, сцен, ссылок или правка исключений обновляют сохранённый отчёт сразу на месте без повторного сканирования мира.
- **Тонированный оверлей статуса:** во время аудита, пакетных правок, удаления или чистки JSON окно затемняется, а по центру отображается кольцо прогресса с процентом, текущим этапом, обрабатываемым ключом или путём и кнопкой отмены там, где операцию можно остановить.

### Темы и шрифты

В шапке открывается меню палитры с темами Ночь (тёмный графит) и Пергамент (тёплый светлый фон) и шестью цветами акцента (`Латунь`, `Угли`, `Аркана`, `Лес`, `Иней`, `Роза`). Для чёткого отображения кириллицы и латиницы в интерфейс встроен шрифт Onest Variable (`OFL-1.1`).

## Диагностика и автофикс

### 1. Тяжёлые сцены и медиа (готово к `v14` Multi-Level)

Проверяет уровни `Scene.levels` (фоны и передние планы), общую графику сцены, тайлы (`Tile`), стены (`Wall`), источники света (`AmbientLight`), свет и видео на токенах (`Token`), видео на рисунках (`Drawing`) и погоду.

- **Что находит:**
  - Текстуры шире или выше `4096 px` либо тяжелее `18 MP`
  - Несжатые или старые растровые форматы (`PNG`, `JPG`, `JPEG`, `BMP`, `TGA`, `TIFF`, `GIF`) вместо `WebP`
  - Сцены с превышением лимита стен (`> 300`), света (`> 40`) или анимаций (`> 15`)
  - Стены нулевой длины и точные дубликаты сегментов (с проверкой типа двери, ограничений, высоты и уровней v14)
- **Автоисправления:**
  - **Конвертация в WebP в браузере:** пережимает растр через `OffscreenCanvas` или `<canvas>` и загружает через `FilePicker` Foundry, не удаляя исходные файлы с диска.
  - **Защита системных папок:** файлы внутри `modules/`, `systems/`, `icons/` и `ui/` на месте не перезаписываются; готовые `.webp` сохраняются в `worlds/<worldId>/waifu-optimized/`, а ссылки в сценах, уровнях и тайлах обновляются автоматически.
  - **Стены и свет:** удаляет лишние дубли и нулевые стены и по желанию отключает анимацию у источников света.

### 2. Сканер битых ссылок `@UUID`

Обходит `JournalEntry` и `JournalEntryPage` (`text.content`, `text.markdown`, `system`, `flags`, в том числе HTML-блоки `data-loreframe-template` и ключи флагов с точками), а также `Actor`, вложенные `Item` и `ActiveEffect`.

- **Что проверяет:** обогатители `@UUID[...]{...}`, ссылки `<a data-uuid="...">`, заголовки `#якорей`, относительные пути `.SubDoc.id` и прямые UUID внутри связных полей в `flags` и `system`.
- **Автоисправление:** подбирает замены по документам мира и загруженным компендиумам с учётом типа `Document` и сходства биграмм Дайса. Поддерживает замену в один клик, пакетное применение `100%` совпадений и удаление ссылки с сохранением текста.

### 3. Настройки мира и осиротевшие флаги

Считает размер UTF-8 JSON для записей `WorldSettings` и пространств флагов на документах мира (при включённой опции ещё и в `game.messages`).

| Статус | Что означает | Поведение при очистке |
| --- | --- | --- |
| **Удалённый модуль** | ID модуля больше нет среди установленных `game.modules` | Входит в пакетную очистку (с необязательным JSON-бэкапом) |
| **Отключённый модуль** | Модуль установлен, но сейчас выключен | Показывается в отчёте; пакетной очисткой не удаляется |
| **Раздутый активный** | Данные активного модуля, системы или ядра превышают порог | Можно открыть в инспекторе и удалить вручную, если это старый кэш |

> [!IMPORTANT]
> Перед удалением настроек мира или флагов WAIFU по умолчанию сохраняет бэкап `waifu-storage-backup-<worldId>-<timestamp>.json` с ключами, UUID целей и самими флагами, чтобы данные можно было восстановить.

## Отчёты и графики

Отчёт можно выгрузить в четырёх форматах:

- **Визуальный HTML (`.html`):** автономный файл с восемью встроенными графиками SVG, переключателем тем Ночь и Пергамент и правилами `@media print` для печати в PDF.
- **Отчёт Markdown (`.md`):** таблицы штрафов, текстовые полосы распределений, статистика сцен (`Мин / Средн. / Медиана / P95 / Макс`), список тяжёлых модулей и таблицы находок.
- **Запись журнала Foundry:** создаёт `JournalEntry` в мире с семантическими HTML-таблицами для ProseMirror.
- **Отчёт JSON (`.json`):** структурированная выгрузка (`schemaVersion: 2`) с блоками `summary`, `statistics` и полными списками проблем.

<details>
<summary><strong>Формула индекса целостности мира (от 0 до 100%)</strong></summary>

Балл стартует со `100`, затем вычитаются ограниченные сверху штрафы по пяти группам:

- **Сцены:** `criticalScenes * 14 + warningScenes * 5`
- **PNG-медиа:** `min(25, pngAssets * 3)`
- **Битые `@UUID`:** `min(35, brokenUuids * 3)`
- **Настройки мира:** `min(18, bloatedSettings * 4 + orphanedSettings * 2)`
- **Флаги документов:** `min(20, orphanedNamespaces * 4 + bloatedFlagEntries * 3)`

Пороги оценки: Норма (`85-100%`), Предупреждение (`60-84%`), Критично (`< 60%`).

</details>

## Настройки и API

### Настраиваемые пороги

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `maxTextureResolution` | `4096` px | Максимальная ширина или высота текстуры карты и тайла |
| `maxMegapixels` | `18` MP | Лимит площади картинки (`ширина × высота / 1 000 000`) |
| `maxAssetBytes` | `15728640` B (15 MB) | Порог веса файла текстуры по HTTP |
| `maxWalls` | `300` | Предел числа сегментов стен на одной сцене |
| `maxLights` | `40` | Предел источников света на одной сцене |
| `maxAnimations` | `15` | Предел суммы анимированного света, видео на сцене/тайлах/токенах и погоды |
| `nearDuplicateWallTolerance` | `2` px | Допуск расстояния между концами для поиска почти совпадающих стен (`0` отключает) |
| `maxSettingBytes` | `16384` B (16 KB) | Лимит размера для отдельной настройки мира |
| `maxFlagBytes` | `32768` B (32 KB) | Лимит размера для пространства флагов на документе |
| `webpQuality` | `0.85` | Качество сжатия WebP (`0.50-1.00`) |
| `downscaleOnConvert` | `false` | Уменьшать текстуры сверх лимита до `maxTextureResolution` при перекодировке в WebP |
| `skipLargerWebp` | `true` | Отменять замену, если WebP вышел тяжелее оригинала (без уменьшения разрешения) |
| `uuidMinAutoConfidence` | `1.0` | Минимальная точность (`0.75-1.00`) для автозамены `@UUID` |
| `maxChatMessages` | `1000` | Порог сообщений чата до предупреждения о раздутом логе |
| `includeChatMessages` | `false` | Проверять ли `game.messages` на забытые флаги модулей |

### Публичный API для макросов и модулей

```js
const waifu = game.modules.get("waifu").api;

// Открыть окно отчёта аудита (автоскан только при первом запуске; далее открывает сохранённый отчёт)
waifu.open();

// Открыть пустое по умолчанию окно drag-and-drop аудита актёров и предметов
waifu.openEntityAudit();

// Получить последний сохранённый отчёт аудита без запуска скана
const lastReport = waifu.getLastReport();

// Запустить аудит программно (с опциональным переопределением порогов)
const report = await waifu.runAudit({ maxWalls: 250 });

// Экспортировать как "markdown", "html" или "json" на языке "en" или "ru"
const html = waifu.exportReport(report, "html", "ru");
const md = waifu.exportReport(report, "markdown", "ru");
```

## Разработка

Нужен Node.js ≥ 24 (`node --test`, без внешних runtime-зависимостей). При пуше тега `v*` GitHub Actions прогоняет проверки и выкладывает ZIP-архив с `module.json` через [release.yml](.github/workflows/release.yml).

```bash
npm run check     # Проверка манифеста, паритета ключей i18n (en/ru), синтаксиса и unit-тесты
npm run deploy    # Копирование рабочих файлов модуля (включая assets/fonts) в локальный Foundry Data/modules/waifu
npm run package   # Сборка dist/waifu-v<версия>.zip и dist/module.json
npm run release   # Запуск проверок и сборка релизного архива
```

## Использование ИИ (AI Disclosure)

При разработке модуля использовались ИИ-инструменты для черновиков кода, рефакторинга, тестов, документации и переводов. Всю архитектуру, код, пользовательские тексты, русскую и английскую локализации проверил, протестировал и поддерживает TacticalOtaku, единственный автор модуля.

Ресурсы внутри пакета полностью соответствуют [политике Foundry VTT в отношении ИИ-контента](https://foundryvtt.com/article/ai-policy/): модуль не содержит сгенерированных ИИ картинок, звука или готовых лорных текстов.
