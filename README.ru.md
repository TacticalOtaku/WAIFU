# WAIFU: World Audit & Integrity

**Инструмент диагностики мира и безопасного автоисправления для Foundry VTT v14+**

## Установка

Вставьте **URL манифеста** в окно установки модулей Foundry VTT (**Дополнительные модули → Установить модуль → Manifest URL**):

```text
https://github.com/TacticalOtaku/WAIFU/releases/latest/download/module.json
```

**Требования:** Foundry VTT **14** (не зависит от игровой системы; ноль внешних зависимостей).  
**Ручная установка:** скачайте `waifu-v<версия>.zip` со страницы [GitHub Releases](https://github.com/TacticalOtaku/WAIFU/releases/latest), распакуйте в `Data/modules/waifu` (чтобы `module.json` находился в корне папки) и включите **WAIFU: Аудит и целостность мира** в управлении модулями мира.

## Обзор

**WAIFU** за считанные секунды проверяет весь мир Foundry VTT, рассчитывает общий индекс целостности мира (`0–100%`), визуализирует узкие места на встроенных SVG-графиках со статистикой распределений, сохраняет последний отчёт даже при перезаходе (автоаудит выполняется только при самом первом запуске, далее все сканы только ручные) и предлагает **безопасные обратимые автоисправления** с необязательным JSON-бэкапом и мгновенным локальным обновлением отчёта без перезапуска аудита после каждой очистки.

> [!NOTE]
> Создан специально для **Foundry VTT v14** (включая многоуровневые `Scene.levels`, `ApplicationV2` и блоки журналов **Loreframe**) с полной **английской** и **русской** локализацией. Оформлен в визуальном языке **AIM: Actor Window** (темы `Ночь` и `Пергамент`, 6 акцентных палитр и встроенный шрифт **Onest Variable**).

## Как открыть WAIFU

Любой пользователь **GM** может открыть панель диагностики четырьмя способами:

| Точка входа | Где найти |
| --- | --- |
| **Элементы управления сценой** | Инструменты токенов (слой `Tokens`) → иконка стетоскопа (**WAIFU: Аудит и целостность мира**) или коробок (**WAIFU: Аудит актёров и предметов**) |
| **Боковая панель настроек** | Вкладка «Настройки игры» → кнопка **Открыть аудит мира (WAIFU)** |
| **Настройки модулей** | Настройка параметров → WAIFU → **Открыть аудит WAIFU** или **Открыть аудит актёров и предметов** |
| **Макрос / Консоль** | `game.modules.get("waifu").api.open()`, `WAIFU.open()` или `WAIFU.openEntityAudit()` |

## Рабочая область

WAIFU использует **3-уровневый интерфейс «Центральный хаб и детализация»** (`Компактная шапка` → `Bento-хаб из 6 окон` → `Вложенная детализация и выдвижные инспекторы 2-го уровня`), который на узких окнах (`< 860 px`) автоматически складывается в компактный список карточек:

| Под-окно / Экран деталей | Сводка в хабе (уровень 0) и детальный режим (уровни 1 и 2) |
| --- | --- |
| **1 · Индекс целостности и тренд** | Радиальный индикатор `270°`, шкала слагаемых штрафов, мини-график тренда и сравнение с JSON → полный график динамики с дельтами, полосы штрафов по категориям, матрица проблем по доменам и распределения метрик сцен (`Мин / Средн. / Медиана / P95 / Макс`). |
| **2 · Автофикс и обслуживание** | Топ-3 приоритетных безопасных исправления в 1 клик и бейджи системных алертов → интерактивная **Очередь Dry-Run** с чекбоксами выбора, встроенной галочкой JSON-бэкапа и инструментами обслуживания мира (архивация чата, удаление пустых боёв, 404-медиа, неиспользуемый `waifu-optimized`, исключения). |
| **3 · Сцены и медиафайлы** | KPI чистых сцен, пропорциональная шкала `WebP / PNG`, топ-2 тяжёлых сцен (клик открывает **выдвижной инспектор сцены**) → график мегапикселей против лимита, поиск и фильтры, мультивыбор строк (с `Shift+Click` и выделением всех видимых) для пакетной конвертации WebP, стен, токенов, света и исключений, сортируемая таблица `Scene.levels` и `Tile`, фокус на холсте и конвертация в WebP. |
| **4 · Ссылки `@UUID` и якоря** | Шкала валидности ссылок и топ проблемных документов → графики валидности, охват `JournalEntry`, `Loreframe`, `Actor`, `Item`, `RollTable`, `Macro`, `Scene`, проверка `#якорей`, панель мультивыбора для замены/отвязки/исключения выбранных строк, подбор замен, ручной каталог, синхронизация `{текста}`, замена в 1 клик и безопасная отвязка. |
| **5 · Хранилище БД и флаги** | Доступный для очистки объём и топ модулей → диаграмма структуры БД и крупнейших модулей, сортируемые таблицы World Settings и флагов документов с мультивыбором (`Shift+Click` и выбор всех видимых) для пакетного удаления или исключения без перезапуска аудита, JSON-инспектор, точечное удаление, **Бэкап и восстановление JSON**, и обслуживание чата/боёв. |
| **6 · Студия отчёта и пороги** | Плитки активных лимитов и быстрая панель экспорта (`.html`, `.md`, `.json`, журнал) → **Предпросмотр отчёта** (`Визуальный \| Markdown \| В журнал`) рядом со встроенным редактором всех **15 порогов и переключателей аудита**. |
| **7 · Аудит актёров и предметов (JSON)** | Встроенный 7-й раздел и отдельное окно (`WAIFU.openEntityAudit()`), **пустое по умолчанию** — перетащите drag & drop любого `Actor`, `Item`, `Folder` (включая вложенные подпапки) или `Compendium` (`Actor`/`Item`) для поиска и безопасной очистки неиспользуемых флагов, `prototypeToken.flags`, `ActiveEffect.changes` и остаточных строк `@UUID` / `modules/<id>/` от удалённых или отключённых модулей без полного аудита мира. |

### Тонированный экран статуса и сохранение отчёта

- **Автоаудит только при первом запуске**: WAIFU автоматически сканирует мир только при самом первом открытии (если сохранённого отчёта ещё нет) и сохраняет последний аудит между перезаходами. Все последующие запуски — только вручную.
- **Локальное обновление без перескана**: при очистке, удалении, замене или исключении параметров отчёт обновляется локально на месте и сразу пересохраняется без повторного аудита мира.
- **Статусный оверлей с прогрессом**: при любом аудите, автофиксе или удалении окно тонируется оверлеем с круговым индикатором, процентом выполнения, текущим этапом и конкретным удаляемым/обрабатываемым объектом (с кнопкой **Отмена**).

### Темы и типографика

Переключайтесь между темами **Ночь** (тёмный графит) и **Пергамент** (тёплый светлый фон) и **6 акцентами** (`Латунь`, `Угли`, `Аркана`, `Лес`, `Иней`, `Роза`) прямо через кнопку палитры в шапке. Подписи интерфейса и табличные цифры используют встроенный шрифт **Onest Variable** (`OFL-1.1`) для чёткой кириллицы и латиницы без доступа в интернет.

## Диагностика и автофикс

### 1. Тяжёлые сцены и медиа (готово к `v14` Multi-Level)

Сканирует уровни сцен `Scene.levels` (фоны и передние планы), базовую графику сцены, тайлы (`Tile`), сегменты стен (`Wall`), источники света (`AmbientLight`), свет/видео-текстуры токенов (`Token`), видео на рисунках (`Drawing`) и погоду сцены (`weather`).

- **Выявляет:**
  - Сверхбольшие текстуры, превышающие максимальную сторону (`4096 px`) или бюджет мегапикселей (`18 MP`)
  - Неоптимизированные растровые форматы (`PNG`, `JPG`, `JPEG`, `BMP`, `TGA`, `TIFF`, `GIF`) вместо `WebP`
  - Избыточное число стен (`> 300`), источников света (`> 40`) или активных анимаций (`> 15`)
  - Стены нулевой длины и точные дубликаты сегментов (с учётом типа двери, ограничений, высоты и уровней `v14`)
- **Безопасные автоисправления:**
  - **Конвертация в WebP прямо в браузере:** перекодирует растровые текстуры через Canvas (`OffscreenCanvas` / `<canvas>`) и загружает через `FilePicker` Foundry. Исходные файлы на диске никогда не удаляются.
  - **Защита системных путей:** ресурсы внутри `modules/`, `systems/`, `icons/`, `ui/` и др. не перезаписываются на месте — WAIFU сохраняет `.webp` в `worlds/<worldId>/waifu-optimized/` и автоматически обновляет ссылки на сцене/уровнях/тайлах.
  - **Очистка геометрии и анимаций:** удаляет дублирующие и нулевые стены и при необходимости отключает анимации на источниках света.

### 2. Сканер битых ссылок `@UUID`

Рекурсивно проверяет `JournalEntry` и `JournalEntryPage` (`text.content`, `text.markdown`, `system`, `flags` — включая HTML-блоки `data-loreframe-template` и ключи флагов с точками), а также `Actor`, встроенные `Item` и `ActiveEffect`.

- **Проверяет:** обогатители `@UUID[...]{...}`, ссылки `<a data-uuid="...">`, цели `#якорей`, относительные ссылки `.SubDoc.id` и голые UUID в связных ключах внутри `flags` / `system`.
- **Автоисправление:** ранжирует кандидатов по документам мира и загруженным компендиумам по типу `Document` и сходству биграмм Дайса; поддерживает **замену в 1 клик**, **пакетную замену `100%` точных совпадений** и **безопасную отвязку**, сохраняющую видимый текст.

### 3. Настройки мира и осиротевшие флаги

Измеряет объём UTF-8 JSON в `WorldSettings` и пространствах имён флагов мировых и вложенных документов (опционально включая `game.messages`).

| Статус | Значение | Поведение автоочистки |
| --- | --- | --- |
| **Удалённый модуль** | ID модуля больше не установлен в `game.modules` | Включается в пакетную очистку сирот (с опциональным JSON-бэкапом) |
| **Отключённый модуль** | Модуль установлен, но сейчас выключен | Подсвечивается для наглядности; **никогда** не затрагивается пакетной очисткой |
| **Раздутый активный** | Данные активного модуля/ядра/системы превышают порог | Доступен для просмотра и ручного удаления, если это устаревший кэш |

> [!IMPORTANT]
> Перед удалением любых настроек мира или пространств флагов WAIFU предлагает флажок **Скачать JSON-бэкап перед удалением (рекомендуется)** (включён по умолчанию), сохраняющий `waifu-storage-backup-<worldId>-<timestamp>.json` с ключами, целями и текущим содержимым флагов.

## Отчёты и графики

Каждый запуск аудита формирует сводный отчёт со встроенными SVG-диаграммами и статистикой:

- **Визуальный HTML-отчёт (`.html`)** — автономный файл со всеми 8 SVG-графиками, переключателем тем «Ночь» / «Пергамент» и правилами `@media print` для аккуратного сохранения в PDF.
- **Отчёт Markdown (`.md`)** — структурированный документ с таблицами штрафов, текстовыми диаграммами распределений, статистикой сцен (`Мин / Средн. / Медиана / P95 / Макс`), топом пространств имён и таблицами проблем.
- **Запись журнала Foundry** — создаёт `JournalEntry` в мире с чистыми семантическими HTML-таблицами, совместимыми с ProseMirror.
- **Отчёт JSON (`.json`)** — полный машиночитаемый отчёт (`schemaVersion: 2`) со сводкой `summary`, статистикой `statistics` и детальными списками находок.

<details>
<summary><strong>Формула индекса целостности мира (0–100%)</strong></summary>

Отсчёт начинается со `100`, далее вычитаются штрафы по пяти ограниченным категориям:

- **Сцены:** `criticalScenes * 14 + warningScenes * 5`
- **PNG-медиа:** `min(25, pngAssets * 3)`
- **Битые `@UUID`:** `min(35, brokenUuids * 3)`
- **Настройки мира:** `min(18, bloatedSettings * 4 + orphanedSettings * 2)`
- **Флаги документов:** `min(20, orphanedNamespaces * 4 + bloatedFlagEntries * 3)`

Состояния: **Норма** (`85–100%`), **Предупреждение** (`60–84%`), **Критично** (`< 60%`).

</details>

## Настройки и API

### Настраиваемые пороги

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `maxTextureResolution` | `4096` px | Отмечать текстуры карт/тайлов, превышающие этот предел по стороне |
| `maxMegapixels` | `18` MP | Отмечать текстуры, превышающие `ширина × высота / 1 000 000` |
| `maxAssetBytes` | `15728640` B (15 MB) | Отмечать текстуры сцен/тайлов, чей размер по HTTP превышает этот порог |
| `maxWalls` | `300` | Отмечать сцены с большим количеством сегментов стен |
| `maxLights` | `40` | Отмечать сцены с большим количеством источников света |
| `maxAnimations` | `15` | Отмечать сцены, превышающие лимит по сумме анимированного света, видео-тайлов/фонов, анимированных токенов и погоды |
| `nearDuplicateWallTolerance` | `2` px | Отмечать почти совпадающие стены в пределах этого расстояния между концами (`0` отключает) |
| `maxSettingBytes` | `16384` B (16 KB) | Отмечать раздутые настройки мира |
| `maxFlagBytes` | `32768` B (32 KB) | Отмечать раздутые пространства имён флагов |
| `webpQuality` | `0.85` | Качество кодирования WebP (`0.50–1.00`) |
| `downscaleOnConvert` | `false` | Пропорционально уменьшать сверхбольшие текстуры до `maxTextureResolution` при конвертации в WebP |
| `skipLargerWebp` | `true` | Не заменять файл, если полученный WebP тяжелее оригинала (без уменьшения разрешения) |
| `uuidMinAutoConfidence` | `1.0` | Минимальная уверенность совпадения (`0.75–1.00`) для пакетной замены `@UUID` |
| `maxChatMessages` | `1000` | Отмечать раздутый лог чата при превышении этого числа сообщений |
| `includeChatMessages` | `false` | Также проверять `game.messages` на осиротевшие флаги модулей |

### Публичный API для макросов и модулей

```js
const waifu = game.modules.get("waifu").api;

// Открыть окно отчёта аудита (автоскан только при первом запуске; далее открывает сохранённый отчёт)
waifu.open();

// Открыть пустое по умолчанию окно drag-and-drop аудита актёров и предметов
waifu.openEntityAudit();

// Получить последний сохранённый отчёт аудита без запуска скана
const lastReport = waifu.getLastReport();

// Запустить аудит программно (с опциональным переопределением порогов)
const report = await waifu.runAudit({ maxWalls: 250 });

// Экспортировать как "markdown", "html" или "json" на языке "en" или "ru"
const html = waifu.exportReport(report, "html", "ru");
const md = waifu.exportReport(report, "markdown", "ru");
```

## Разработка

Требуется **Node.js ≥ 24** (`node --test` и ноль runtime-зависимостей). Тегированные релизы (`v*`) прогоняют проверки и публикуют ZIP-архив с `module.json` через [release.yml](.github/workflows/release.yml).

```bash
npm run check     # Проверка манифеста, паритета ключей i18n (en/ru), синтаксиса и unit-тесты
npm run deploy    # Копирование рабочих файлов модуля (включая assets/fonts) в локальный Foundry Data/modules/waifu
npm run package   # Сборка dist/waifu-v<версия>.zip и dist/module.json
npm run release   # Запуск проверок и сборка релизного архива
```

## Использование ИИ (AI Disclosure)

При разработке использовались ИИ-инструменты как вспомогательный ассистент (черновики кода, рефакторинг, тесты, документация и переводы). Вся архитектура, код, логика работы, пользовательские тексты и русская/английская локализации проверены, протестированы и поддерживаются владельцем репозитория **TacticalOtaku**, который является единственным автором модуля.

Все включённые в пакет ресурсы и материалы соответствуют [политике Foundry VTT в отношении ИИ-контента](https://foundryvtt.com/article/ai-policy/) — модуль не содержит заранее сгенерированных ИИ-артов, аудио или лорного контента.
